### 📌 Description (curta)

Sistema web para gerenciamento e acompanhamento de operações logísticas (Qlog), com interface moderna em React/Vite, backend Node.js e banco SQLite, focado em simplicidade, performance e rastreabilidade de processos.

---

## 📄 README.md

```markdown
# Qlog

Sistema web para gerenciamento de operações logísticas, com foco em controle de processos, produtividade e acompanhamento de performance de usuários.

## 🚀 Tecnologias

- Frontend: React + Vite + TypeScript
- UI: Tailwind + Shadcn/UI
- Backend: Node.js (server simples)
- Banco de dados: SQLite

---

## 📁 Estrutura do Projeto

```

Qlog/
├─ src/                # Frontend (React)
├─ server/             # Backend Node
├─ database/           # Banco SQLite
├─ dist/               # Build do frontend
├─ docs/               # Documentação técnica

````

---

## ⚙️ Instalação

### 1. Clonar o repositório

```bash
git clone <repo-url>
cd Qlog
````

### 2. Instalar dependências

```bash
npm install
```

ou

```bash
pnpm install
```

---

## ▶️ Rodando o projeto

### Ambiente de desenvolvimento

```bash
npm run dev
```

### Backend

```bash
node server/dev.js
```

---

## 🏗️ Build

```bash
npm run build
```

Arquivos gerados em:

```
/dist
```

---

## 🗄️ Banco de Dados

O projeto utiliza SQLite com o arquivo:

```
/database/Qlog.db
```

* O banco está versionado no repositório
* Não é necessário setup adicional
* Ideal para ambiente simples e rápido

---

## 📌 Funcionalidades

* Login de usuários
* Abertura e acompanhamento de operações
* Controle de processos abertos/fechados
* Painel de performance
* Área de supervisor
* Interface moderna e responsiva



```
